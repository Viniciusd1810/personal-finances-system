# Personal Finances System

A personal finance management system built as a long-term software engineering learning project.

The goal of this project is not only to build a working application, but also to document the evolution of its architecture, testing strategy, security practices, and development decisions.

## Goals

- Practice Test-Driven Development (TDD)
- Apply layered architecture concepts
- Improve Python development skills
- Implement secure authentication practices
- Document architectural decisions
- Build the project incrementally
