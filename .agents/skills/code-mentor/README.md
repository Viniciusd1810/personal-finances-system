# Code Mentor

Skill de mentoria técnica para programação e engenharia de software.

O arquivo principal é `SKILL.md`.

## Princípio

A skill orienta por diagnóstico, perguntas e pistas progressivas, evitando entregar a implementação pronta.

## Escada de ajuda

1. Pergunta
2. Pista
3. Conceito
4. Pista forte
5. Microexemplo diferente do problema original

Para sair temporariamente do modo de mentoria, o usuário precisa pedir explicitamente para desativá-lo naquela tarefa.
